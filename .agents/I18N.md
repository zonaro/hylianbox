# Internationalization (i18n) — HylianBox

## 1. Rule (Hard Rule 8)

Every user-facing string MUST live in `strings.xml`. Default `values/` = **pt-BR**. Provide `values-en/` and `values-es/`. Zero hardcoded strings in Kotlin/XML layouts. No emojis in code/resources (Hard Rule 7).

## 2. Locale Files

| File                                     | Locale                             |
| ---------------------------------------- | ---------------------------------- |
| `app/src/main/res/values/strings.xml`    | pt-BR (default, authored by Bruce) |
| `app/src/main/res/values-en/strings.xml` | English (US)                       |
| `app/src/main/res/values-es/strings.xml` | Spanish (ES/LA neutral)            |

## 3. Translation Process (Wally)

1. Bruce completes pt-BR strings for a feature.
2. Wally translates to en/es (context-aware, not literal).
3. Validate: no missing keys, no hardcoded strings in code.
4. Special terms:
   - "Base ROM" → "ROM Base" (pt-BR) / "Base ROM" (en) / "ROM Base" (es)
   - "Patch" → "Patch" (all)
   - "Hack" → "Hack" (pt-BR/en) / "Hack" (es)
   - "Achievement" → "Conquista" (pt-BR) / "Achievement" (en) / "Logro" (es)
   - "Leaderboard" → "Ranking" (pt-BR) / "Leaderboard" (en) / "Clasificación" (es)
   - "Hardcore" → "Hardcore" (all)
   - "Seed" → "Seed" (all)

## 4. RetroAchievements Exception

Achievement titles/descriptions come from the RA API in English — **do NOT translate** (community canonical terms). Only UI chrome (tabs, buttons, errors, placeholders) is translated.

## 5. Switch UI Strings Scope

- Dock labels: "Loja", "RetroAchievements", "Sobre/Licenças"
- Settings > Appearance: "Aparência", "Tema", "Sons da Interface", "Cor de Destaque"
- Grid header: "Todos os Jogos"
- Search/filter hints: "Buscar hacks...", "Filtrar por tag..."
- Theme toggle: "Tema escuro" / "Tema claro"
- SFX toggle: "Efeitos sonoros de navegação"
- Footer status: gamepad connected/disconnected (no About hint; About lives in Settings > Sobre)
- Splash: no strings (logo is artwork)
- In-game menu chrome: "Pausar", "Conquistas", "Rankings", "Auto-Ocarina", "Configurações de Vídeo", "Controles"

### Touch overlay terminology

The in-game Controls section exposes one persisted overlay-mode selector. Keep the product labels
consistent in all three locales:

| Meaning                         | pt-BR (default)      | English             | Spanish              |
| ------------------------------- | -------------------- | ------------------- | -------------------- |
| Selector                        | Modo de controle     | Control mode        | Modo de control      |
| Existing visible-button overlay | Standard — Controles | Standard — Controls | Standard — Controles |
| Minimal mapped-area overlay     | Pro — Área de Toque  | Pro — Touch Areas   | Pro — Áreas táctiles |

`Toque Área Direita` / `Right Area Tap` / `Toque Área Derecha` is retired from the in-game menu.
Its behavior belongs only to the Pro mapped-area overlay and is not presented as a separate setting.
The mapped zones themselves have no visible text, borders, or button labels; only their color glows
and pressed/drag feedback are drawn, so they require no accessibility copy unless the implementation
adds a user-facing tutorial or mode description.

## 6. Quality Gates

- Zero missing string keys in en/es vs pt-BR.
- No machine-translation artifacts (e.g., "Save State" → "Salvar Estado" not "Estado de Salvamento").
- All public APIs have KDoc with `@param`, `@return`, `@throws` (Wally).
